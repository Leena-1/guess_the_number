🎯 Guess The Number Game

An interactive browser-based number guessing game where players try to guess a randomly generated number within limited attempts. The game provides hints after each guess and tracks previous attempts.

🧠 Project Overview

This project demonstrates core JavaScript concepts such as:

DOM Manipulation

Event Handling

Random Number Generation

User Input Validation

Game State Management

It is designed to provide a simple yet engaging user experience while strengthening frontend development fundamentals.

✨ Features

✅ Random number generated between 1 and 100
✅ Limited number of attempts
✅ Displays previous guesses
✅ Provides high / low hints
✅ Game reset functionality
✅ Responsive UI
✅ Beginner-friendly game logic

🖥️ Tech Stack

HTML5 – Structure

CSS3 – Styling and UI design

JavaScript (Vanilla JS) – Game logic and interactivity

Vercel – Deployment and hosting

🎮 How To Play

Enter a number between 1 and 100

Click Submit

The game will tell you if your guess is:

Too high

Too low

Continue guessing until you win or attempts finish

Restart game to play again

⚙️ Installation & Setup

If you want to run this project locally:

Step 1: Clone Repository
git clone https://github.com/Leena-1/guess-number-game.git

Step 2: Open Project Folder
cd guess-number-game

Step 3: Run Project

Simply open index.html in your browser.
